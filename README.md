# [QUTCC: Quantile Uncertainty Training and Conformal Calibration](https://arxiv.org/abs/2507.14760)
The official PyTorch implementation of the [QUTCC: Quantile Uncertaint Training and Conformal Calibration for Imaging Inverse Problems]([https://arxiv.org/abs/2310.16102](https://arxiv.org/abs/2507.14760))


# Setup: 

Clone this project using:

```
git clone https://github.com/cassandra-t-ye/QUTCC.git
```

Dependencies can be installed using

```
conda env create -f environment.yml
source activate qutcc
```
